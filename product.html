01
01 / 四步链路

采集、核对、入库、复盘，
一条链路走完。

没有黑箱，也没有一步被跳过。点开任意一段，看它具体拦下了什么。

把材料收进来

截图、录屏、xlsx、营地链接，四种入口最后落在同一条链路上。

  • 拖拽或粘贴导入，重复文件按指纹去重
  • 录屏按时间轴抽帧，跳过加载与 BP 段
  • 营地链接直接带出对局列表与结算面板

输入截图 / 录屏 / 表格 / 营地链接

先给人看，再入库

识别结果一律是候选值。名字、英雄、经济对不上时，停下来问你。

身份冲突不会被一次误识别静默覆盖。
  • 同一选手的多个营地昵称合成一个 ID
  • 低置信度字段单独列出，可批量确认
  • 改过的值留痕，不会静默覆盖原文

拦截身份冲突 / 低置信度 / 重复对局

每个数字带出处

写入前过一遍字段契约；缺失就写缺失，不补造。

  • 字段标明来源：截图 / 录屏 / 表格 / 营地
  • 同一指标带样本数，样本不足直接标注
  • data/ 目录就是数据库，拷走即备份

校验字段契约 / 样本数 / 缺失标记

把一局讲成一页

时间线、经济曲线、掉点定位、阵容对照，投到同一屏就能开会。

  • 周期、对手、选手、英雄四个切口互相对照
  • 阵容与 BP 顺序回放到具体分钟
  • 导出 PDF 直接进训练小结

输出一页看懂 / 周期对照 / PDF

    03 / 输出

    复盘会上，
    只放一页。

    时间线、经济曲线、掉点位置、阵容对照，投出来就是结论本身，不用再截图拼 PPT。

    一屏之内

    比分、经济、掉点、阵容同屏对照，投屏不用切页，也不用一边翻网页一边讲。

    每个数字有出处

    字段标明来源与样本数；缺失直接标出来，不补造，也不给“看起来差不多”的平均值。

    能带走

    导出 PDF 进训练小结；整个 data/ 拷走就是完整备份，换电脑覆盖过去就能接着用。
