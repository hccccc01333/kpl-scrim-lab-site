安装与升级

Windows 10 / 11，全程约 5 分钟。安装包和免安装包都内置 Python 运行时与依赖，不需要另外装环境。

两种装法，选一个

方式适合怎么用
安装包（推荐） 日常使用、给教练组部署 双击 KPL-Scrim-Lab-1.5.32-setup.exe，按提示装到当前用户目录（不需要管理员权限）
免安装包 不想写注册表、放 U 盘带走 解压 KPL-Scrim-Lab-1.5.32-full.zip 到固定目录，双击 启动工作台.bat

装完第一次启动

  1. 启动

    安装版双击桌面「KPL 赛训工具」；免安装版双击 启动工作台.bat。

    服务在后台启动，就绪后自动打开浏览器，地址是 127.0.0.1:8766。没有控制台窗口，也不会因为关掉浏览器而停止。

    第一次打开如果还没有对局，首屏会给三条路：扫码采集（推荐）、看一场示例、导入表格 / 截图；选一条就能开始，不需要先看懂所有页面。

    如果之前用的是免安装版，首页会自动发现旧数据目录，显示局数与更新时间，点「搬到这台电脑」就把整个库搬过来（回放与录屏可选）。旧目录不会被改动，当前库已有对局时不会执行。

  2. 绑定营地（只用截图和表格可以跳过）

    进「采集通道」→「营地自动同步」→ 用打过训练赛的教练微信扫码授权。授权凭证存在 data/camp_auth.json，等同于账号登录态，不要外传。

  3. 加入选手

    让选手在王者营地分享任意一局，把链接粘进「加入清单」；系统会从链接里识别营地 ID。一个稳定上场的选手就能覆盖全队每局。

  4. 开始采集

    选选手 →「获取对局列表」→ 勾选要的局 →「拉取选中」。或者直接导入赛后截图、xlsx 表格。

以后怎么升级

启动后工作台会在右下角静默检查新版本，发现更新时点「立即更新」：下载增量包 → 校验 SHA-256 → 暂存 → 重启替换 → 健康检查，失败自动回滚到上一版本。data、.env、营地授权不在更新范围内。

国内网络会优先从 Gitee 镜像检查更新，GitHub 只作为海外备用；更新包和清单都带 SHA-256，下载不完整不会替换程序。

完全离线的机器，可以让作者把 patch-版本号.zip 发过来，在更新提示里选「选择本地更新包」。

Windows 提示「未知发布者」？ 项目没有购买代码签名证书。点「更多信息 → 仍要运行」，或右键安装包 → 属性 → 勾选「解除锁定」再双击。 经微信、U 盘传过去的文件通常不会触发这个提示。安装器不申请管理员权限，不会弹 UAC。

数据、备份与迁移

所有数据保存在安装目录的 data 文件夹：数据库、比赛记录、导入文件、授权、备份都在里面。

  • 备份

    整个 data 文件夹拷走即可，不需要额外的导出步骤。

  • 迁移

    新电脑装好后，把旧机器的 data 覆盖过去，重启工作台即可延续全部记录。

  • 卸载

    从「应用和功能」卸载会删除程序文件，但保留 data；确认不再需要时手动删除整个安装目录。

出了问题先看日志。安装版开始菜单里有「打开日志目录」，launcher.log 记录启动过程， server.log 记录服务输出。把这两个文件发给支持人员，比描述「打不开」有用得多。

常见问题

数据会上传到你们的服务器吗？

不会。平台没有云端服务，识别、入库、分析都在本机完成，数据只写在本地 data 目录。唯一的外部请求是你主动发起的营地同步与更新检查。

需要先装 Python 或者配置环境吗？

不需要。安装包和免安装包都内置了 Python 运行时与依赖，解压或安装后直接双击即可。源码运行才需要 Python 3.11 / 3.12（3.13 暂不支持）。

支持 macOS、平板或手机吗？

目前只提供 Windows 10 / 11 桌面端。界面是自适应的，局域网内可以用平板浏览器访问同一台电脑上的服务（默认关闭，需要显式开启）。

更新会覆盖我的比赛数据吗？

不会。增量更新只替换程序文件，data、.env 与营地授权不在更新范围内；更新失败会自动回滚到上一版本。卸载程序也不会删除 data。

安装时 Windows 提示「未知发布者」怎么办？

项目没有购买代码签名证书。点「更多信息 → 仍要运行」即可，或右键安装包 → 属性 → 勾选「解除锁定」。经微信、U 盘传过去的文件通常不会触发提示。

收费吗？俱乐部用需要授权吗？

个人学习、学术研究与非营利组织可以免费使用。职业俱乐部、训练机构等商业场景需要单独授权，见 LICENSE 或直接联系作者。
